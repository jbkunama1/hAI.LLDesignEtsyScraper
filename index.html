🛍️ hAI.LLDesignEtsyScraper

CLI-Tool zum Exportieren von Etsy-Shop-Listings via API v3

Python Docker whiptail Agent-tauglich

🎯 Features

📦 CSV-Export

Alle Listings mit Titel, Beschreibung, Preis, Tags, Materialien, Kategorie

🖼️ Bilder-Download

Optionales Herunterladen aller Produktbilder

🚚 Versandinfos

Versandprofile und Kosten automatisch extrahieren

🎨 whiptail-Menü

Interaktive Bedienung für manuelle Nutzung

🤖 Agent-tauglich

Voll automatisierbar über CLI-Args und Umgebungsvariablen

🐳 Docker-freundlich

Container-basiertes Deployment auf DietPi/Raspberry Pi

🚀 Quick Start

1. Installation

# Abhängigkeiten installieren
sudo apt-get update
sudo apt-get install -y python3 python3-pip whiptail

# Python-Abhängigkeiten
pip3 install -r requirements.txt

# Skript ausführbar machen
chmod +x etsy-shop-exporter.py

2. Konfiguration

Erstelle eine .env-Datei:

ETSY_API_KEY=dein_api_key
ETSY_SHARED_SECRET=dein_shared_secret
ETSY_ACCESS_TOKEN=dein_access_token
ETSY_SHOP_ID=12345678
ETSY_OUTPUT_DIR=./etsy_export
ETSY_DOWNLOAD_IMAGES=1

3. Tool starten

# Umgebungsvariablen laden
source .env

# Export starten
python3 etsy-shop-exporter.py --no-menu

🐳 Docker-Nutzung

Image bauen

docker build -t etsy-shop-exporter .

Container starten

docker run -it --rm \
  -v $(pwd)/etsy_export:/app/etsy_export \
  -e ETSY_API_KEY="dein_api_key" \
  -e ETSY_SHARED_SECRET="dein_shared_secret" \
  -e ETSY_ACCESS_TOKEN="dein_access_token" \
  -e ETSY_SHOP_ID="12345678" \
  -e ETSY_DOWNLOAD_IMAGES="1" \
  etsy-shop-exporter --no-menu
